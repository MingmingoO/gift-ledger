# 礼金往来记账

一个免费的网页小程序，用于记录个人礼金（人情）往来。支持**分人、分时段查询**，可对应查看**收礼与送礼**，自动生成**人情统计**，并支持**多账号各自独立查看**自己的数据。

- 前端：纯 HTML/CSS/JS，无需打包，可直接托管到 GitHub Pages（免费长期）。
- 数据：默认存在浏览器本地；在「设置」中填入 Supabase 信息即可升级为**云端同步**（多设备、多账号）。
- 备份：一键导出 / 导入 JSON，可保存到百度网盘等做长期备份。

---

## 一、本地预览（最快看到效果）

直接双击 `index.html` 即可打开（部分浏览器对本地文件有限制，建议用下面的方式起一个本地服务）：

```bash
# 在项目目录下
python -m http.server 8000
# 浏览器打开 http://localhost:8000
```

进入后输入任意「账号名」即可开始记账（数据只存在你这台浏览器里）。

---

## 二、开启云端同步（Supabase，可选但推荐）

云端模式让**不同账号看到不同数据**，且换手机 / 电脑都能看到同一份记录。

### 1. 创建 Supabase 项目
1. 打开 https://supabase.com ，用 GitHub 注册并登录。
2. 新建一个项目（New Project），区域任选，记住你设置的数据库密码。
3. 进入项目后，左侧菜单 **SQL Editor → New query**。

### 2. 建表（复制粘贴即可）
把本项目 `supabase/schema.sql` 的全部内容粘贴进去，点击 **Run**。
它会创建 `gift_records` 表，并开启**行级安全（RLS）**——每个账号只能看自己的数据。

### 3. 获取连接信息
1. 左侧 **Project Settings → API**。
2. 复制 `Project URL` 和 `anon public` 那串 key。

### 4. 填进小程序
1. 打开记账网页，点右上角「设置」。
2. 把 URL 和 anon key 分别填到「云端同步」里，点「保存并连接」。
3. **刷新页面**，登录界面会变成「邮箱 + 密码」。
4. 首次使用点「注册」用邮箱注册一个账号，之后用「登录」即可。

> 提示：Supabase 免费额度对个人完全够用（500MB 数据库、5 万月活用户）。

## 三、部署到 GitHub Pages（免费长期托管）

1. 在 GitHub 新建一个仓库（如 `gift-ledger`）。
2. 把本项目全部文件（`index.html`、`assets/`、`supabase/`）推送进去：
   ```bash
   git init
   git add .
   git commit -m "礼金往来记账"
   git branch -M main
   git remote add origin https://github.com/你的用户名/gift-ledger.git
   git push -u origin main
   ```
3. 仓库 **Settings → Pages**，Source 选择 `Deploy from a branch`，分支选 `main`、目录选 `/ (root)`，保存。
4. 几分钟后访问 `https://你的用户名.github.io/gift-ledger/` 即可。
5. 首次打开后到「设置」填入 Supabase 信息，就能云端同步了。

## 四、数据备份（网盘）

无论本地还是云端模式，都可以在「设置」里：
- **导出 JSON**：下载一个备份文件，存到百度网盘等。
- **导入 JSON**：换设备或恢复时，上传该文件即可还原（导入会覆盖当前账号数据，建议先导出）。

## 五、功能说明

| 页面 | 功能 |
|------|------|
| 记账 | 添加一笔（收礼 / 送礼、往来人、事件类型、金额、日期、备注），可编辑 / 删除 |
| 明细 | 按**往来人 / 起止日期 / 类型 / 事件**组合筛选，查看收礼与送礼对应情况 |
| 统计 | 总收礼、总送礼、净人情；按月趋势图；按人排行；人情账本（谁欠谁人情） |
| 设置 | 配置云端同步、导出 / 导入备份、载入示例数据、清空数据 |

**人情账本**中“净额”含义：
- 正数（绿）：别人给你多 → 你**欠人情**，记得回礼；
- 负数（红）：你给别人多 → **欠你人情**；
- 0：已平。
